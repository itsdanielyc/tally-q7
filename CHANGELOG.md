# Changelog

## [0.1.0] - 2026-11-18

### Added

- Record, edit, and delete transactions in a local ledger that reopens after a restart.
- Map bank CSV columns, preview the result, review rejected rows by line, and skip duplicates.
- Manage categories and apply payee rules to bank imports or uncategorised transactions.
- Browse monthly income, spending, and category budgets.
- Search and filter transactions, export the displayed rows to CSV, and undo the latest deletion, category merge, or import.

### Installation

- Windows x64 uses an unsigned NSIS installer. Microsoft Defender SmartScreen may show “Windows protected your PC”. Windows signing requires a paid code-signing certificate or signing service.
- macOS Apple silicon uses a DMG without Developer ID signing or notarization. Gatekeeper may show that Apple could not verify the app is free of malware. Developer ID signing and notarization require a paid annual Apple Developer Program membership.
- Linux x64 uses an unsigned DEB or AppImage. SHA-256 checksums cover all four installer bundles.
